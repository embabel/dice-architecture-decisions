# Design

The decision reader is an editorial proof sheet. An ivory page and dark navy audit margin separate the approved document from the rule-derived review. Copper marks superseded evidence. The review stays adjacent to its source rows on wide screens and moves directly beneath the time controls on narrow screens.

## Type and color

- Young Serif sets the archived decision and section titles. Use the system sans for running copy and controls. Use system mono for paths, timestamps, reference IDs, and rule text.
- Keep ink on warm paper for evidence. Keep the derived result on navy with light text. Use copper for superseded status and muted teal for a holding premise.
- All statuses have text. Color and small dot shapes reinforce the labels.

## Interaction

- A single date control switches the reconstructed evidence and marks the selected revision. The approved decision stays present in both views.
- Rule traces expand where the conclusion appears. Source links land directly on an excerpt and highlight it.
- Retain visible keyboard focus and readable source paths when columns collapse. Avoid scroll-dependent behavior that hides evidence.
